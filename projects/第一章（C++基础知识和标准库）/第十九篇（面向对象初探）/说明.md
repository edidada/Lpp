C++ 是一种支持 **面向对象编程（OOP，Object-Oriented Programming）** 的编程语言。面向对象编程的核心思想是将程序中的数据和操作数据的方法封装在一起，形成“对象”，并通过对象之间的交互来实现程序功能。下面基于上面的代码，详细讲解 C++ 面向对象编程的核心概念。

---

### 1. **类（Class）**
类是面向对象编程的核心概念，它是一种用户自定义的数据类型，用于描述对象的属性和行为。

在上面的代码中，`AirlineTicket` 是一个类，它定义了航空机票的属性和行为：
```cpp
export class AirlineTicket
{
public:
    // 成员函数声明
    double calculatePriceInDollars();
    std::string getPassengerName();
    void setPassengerName(std::string name);
    int getNumberOfMiles();
    void setNumberOfMiles(int miles);
    bool hasEliteSuperRewardsStatus();
    void setHasEliteSuperRewardsStatus(bool status);

private:
    // 成员变量（属性）
    std::string m_passengerName{ "Unknown Passenger" };
    int m_numberOfMiles{ 0 };
    bool m_hasEliteSuperRewardsStatus{ false };
};
```

- **成员变量（属性）**：描述对象的特征，例如 `m_passengerName`（乘客姓名）、`m_numberOfMiles`（里程数）等。
- **成员函数（方法）**：定义对象的行为，例如 `calculatePriceInDollars()`（计算机票价格）、`setPassengerName()`（设置乘客姓名）等。

---

### 2. **对象（Object）**
对象是类的实例，是类的具体化。通过对象可以访问类中定义的属性和方法。

在上面的代码中，`myTicket` 是 `AirlineTicket` 类的一个对象：
```cpp
AirlineTicket myTicket;  // 创建一个 AirlineTicket 对象
```

- 对象是类的实例化，它占用内存空间。
- 通过对象可以调用类中定义的成员函数，例如：
  ```cpp
  myTicket.setPassengerName("Sherman T. Socketwrench");  // 设置乘客姓名
  myTicket.setNumberOfMiles(800);  // 设置里程数
  ```

---

### 3. **封装（Encapsulation）**
封装是将数据和操作数据的方法绑定在一起，并隐藏内部实现细节，只暴露必要的接口。

在 `AirlineTicket` 类中：
- 成员变量（如 `m_passengerName`、`m_numberOfMiles`）被声明为 `private`，外部无法直接访问。
- 成员函数（如 `setPassengerName()`、`getPassengerName()`）被声明为 `public`，外部可以通过这些函数间接访问或修改私有数据。

例如：
```cpp
myTicket.setPassengerName("Sherman T. Socketwrench");  // 通过公有方法设置私有成员变量
std::string name = myTicket.getPassengerName();  // 通过公有方法获取私有成员变量
```

**封装的好处**：
- 保护数据不被外部直接修改，确保数据的完整性。
- 隐藏内部实现细节，降低代码的耦合性。

---

### 4. **构造函数与析构函数**
- **构造函数**：用于初始化对象，在对象创建时自动调用。
- **析构函数**：用于清理对象，在对象销毁时自动调用。

在上面的代码中，虽然没有显式定义构造函数和析构函数，但编译器会生成默认的构造函数和析构函数。

例如：
```cpp
// 默认构造函数
AirlineTicket::AirlineTicket()
    : m_passengerName{ "Unknown Passenger" }
    , m_numberOfMiles{ 0 }
    , m_hasEliteSuperRewardsStatus{ false }
{
}

// 默认析构函数
AirlineTicket::~AirlineTicket()
{
    // 无需清理操作
}
```

---

### 5. **成员函数与成员变量**
- **成员变量**：描述对象的属性，例如 `m_passengerName`、`m_numberOfMiles`。
- **成员函数**：描述对象的行为，例如 `calculatePriceInDollars()`、`setPassengerName()`。

例如：
```cpp
double AirlineTicket::calculatePriceInDollars()
{
    if (hasEliteSuperRewardsStatus()) {
        return 0;  // 精英客户免费
    }
    return getNumberOfMiles() * 0.1;  // 普通客户按里程计费
}
```

---

### 6. **访问控制**
C++ 通过访问修饰符（`public`、`private`、`protected`）控制类成员的访问权限：
- **`public`**：公有成员，外部可以访问。
- **`private`**：私有成员，只有类内部可以访问。
- **`protected`**：保护成员，类内部和派生类可以访问。

在 `AirlineTicket` 类中：
```cpp
public:
    double calculatePriceInDollars();  // 公有成员函数
private:
    std::string m_passengerName;  // 私有成员变量
```

---

### 7. **面向对象编程的优势**
- **模块化**：将程序分解为多个类，每个类负责特定的功能。
- **可重用性**：类可以被多次实例化，代码复用性高。
- **可维护性**：封装和隐藏实现细节，便于修改和维护。
- **扩展性**：通过继承和多态，可以轻松扩展程序功能。

---

### 8. **代码示例详解**
以下是 `main` 函数中的代码详解：
```cpp
int main()
{
    // 创建一个 AirlineTicket 对象
    AirlineTicket myTicket;  // 调用默认构造函数

    // 设置乘客姓名
    myTicket.setPassengerName("Sherman T. Socketwrench");

    // 设置里程数
    myTicket.setNumberOfMiles(800);

    // 计算机票价格
    double cost{ myTicket.calculatePriceInDollars() };

    // 输出机票价格
    println("This ticket will cost ${}", cost);
}
```

- **对象创建**：`AirlineTicket myTicket;` 创建了一个 `AirlineTicket` 对象。
- **方法调用**：通过对象调用类中的公有方法，例如 `setPassengerName()`、`calculatePriceInDollars()`。
- **数据封装**：通过公有方法间接访问私有成员变量。

---

### 总结
C++ 的面向对象编程通过类、对象、封装、构造函数、析构函数等机制，提供了一种结构化的编程方式。通过面向对象编程，可以更好地组织代码，提高代码的可读性、可维护性和可扩展性。
