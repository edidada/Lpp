`switch` 是 C++ 中的一种条件控制语句，用于根据变量的值执行不同的代码块。它通常用于替代多个 `if-else` 语句，使代码更简洁易读。

### 基本语法

```cpp
switch (expression) {
    case constant1:
        // 当 expression 等于 constant1 时执行的代码
        break;
    case constant2:
        // 当 expression 等于 constant2 时执行的代码
        break;
    // 可以有任意数量的 case 语句
    default:
        // 当 expression 不等于任何 case 常量时执行的代码
        break;
}
```

### 关键点

1. **expression**:
    - `switch` 语句中的 `expression` 必须是一个整型或枚举类型（如 `int`, `char`, `enum` 等）。
    - `expression` 的值会与每个 `case` 标签中的常量进行比较。

2. **case**:
    - 每个 `case` 标签后跟一个常量值，表示当 `expression` 的值与该常量匹配时，执行对应的代码块。
    - `case` 标签中的常量必须是编译时常量，且不能重复。

3. **break**:
    - `break` 语句用于终止 `switch` 语句的执行。如果没有 `break`，程序会继续执行后续的 `case` 或 `default` 代码块，直到遇到 `break` 或 `switch` 语句结束。
    - 这种现象称为“贯穿”（fall-through），有时可以利用它来实现多个 `case` 共享同一段代码。

4. **default**:
    - `default` 标签是可选的，用于处理 `expression` 不匹配任何 `case` 常量的情况。
    - 如果没有 `default`，且 `expression` 不匹配任何 `case`，则 `switch` 语句不执行任何代码。

### 示例

```cpp
#include <iostream>
using namespace std;

int main() {
    int day = 3;

    switch (day) {
        case 1:
            cout << "Monday" << endl;
            break;
        case 2:
            cout << "Tuesday" << endl;
            break;
        case 3:
            cout << "Wednesday" << endl;
            break;
        case 4:
            cout << "Thursday" << endl;
            break;
        case 5:
            cout << "Friday" << endl;
            break;
        case 6:
            cout << "Saturday" << endl;
            break;
        case 7:
            cout << "Sunday" << endl;
            break;
        default:
            cout << "Invalid day" << endl;
            break;
    }

    return 0;
}
```

### 输出

```
Wednesday
```

### 贯穿（Fall-through）示例

```cpp
#include <iostream>
using namespace std;

int main() {
    int day = 3;

    switch (day) {
        case 1:
        case 2:
        case 3:
        case 4:
        case 5:
            cout << "Weekday" << endl;
            break;
        case 6:
        case 7:
            cout << "Weekend" << endl;
            break;
        default:
            cout << "Invalid day" << endl;
            break;
    }

    return 0;
}
```

### 输出

```
Weekday
```

### 注意事项

1. **变量声明**:
    - 在 `switch` 语句中，不能在 `case` 标签中直接声明变量，除非使用花括号 `{}` 创建一个新的作用域。

   ```cpp
   switch (x) {
       case 1:
           int y = 10; // 错误：变量声明不能在 case 标签中
           break;
       case 2:
           {
               int z = 20; // 正确：使用花括号创建新的作用域
               break;
           }
   }
   ```

2. **枚举类型**:
    - `switch` 语句常用于处理枚举类型，使代码更具可读性。

   ```cpp
   enum Color { RED, GREEN, BLUE };

   Color c = GREEN;

   switch (c) {
       case RED:
           cout << "Red" << endl;
           break;
       case GREEN:
           cout << "Green" << endl;
           break;
       case BLUE:
           cout << "Blue" << endl;
           break;
   }
   ```

### 总结

`switch` 语句是 C++ 中用于多分支选择的控制结构，适用于处理多个固定值的条件判断。合理使用 `switch` 可以使代码更加简洁和高效。
