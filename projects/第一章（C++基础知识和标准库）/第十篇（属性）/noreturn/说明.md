`[[noreturn]]` 是 C++11 引入的一个属性（attribute），用于标记一个函数 **不会返回** 到它的调用点。具体来说，它告诉编译器和开发者，这个函数在执行完毕后不会正常返回，而是会通过某种方式终止程序的执行（例如调用 `exit`、抛出异常、进入无限循环等）。

### 详细解释

1. **语义含义**：
  - 当一个函数被标记为 `[[noreturn]]` 时，编译器知道这个函数不会返回到调用点。
  - 这意味着在函数调用之后的代码是不可达的（unreachable），编译器可以据此进行优化。

2. **典型用途**：
  - 用于标记那些会终止程序执行的函数，例如：
    - 调用 `exit` 或 `abort` 终止程序。
    - 抛出异常（但异常会被捕获时，函数仍可能返回）。
    - 进入无限循环（例如 `while (true) {}`）。

3. **编译器优化**：
  - 编译器可以根据 `[[noreturn]]` 属性优化代码。例如：
    - 在函数调用之后的代码可以被移除，因为它是不可达的。
    - 编译器可以避免生成不必要的返回指令。

4. **示例代码分析**：
   ```cpp
   [[noreturn]] void forceProgramTermination()
   {
       exit(1);  // 调用 exit 终止程序
   }
   ```
  - 这里 `forceProgramTermination` 被标记为 `[[noreturn]]`，因为它调用了 `exit`，程序会在此终止，不会返回到调用点。

5. **注意事项**：
  - 如果标记为 `[[noreturn]]` 的函数实际上返回了（例如没有调用 `exit` 或抛出异常），则行为是未定义的（undefined behavior）。
  - 这种函数通常用于处理严重错误或不可恢复的情况。

6. **与 `void` 的区别**：
  - `void` 表示函数没有返回值，但函数仍然会返回到调用点。
  - `[[noreturn]]` 表示函数不会返回到调用点。

### 示例场景

```cpp
#include <iostream>
#include <cstdlib>  // 包含 exit 函数

// 标记为 [[noreturn]]，因为函数不会返回
[[noreturn]] void fatalError(const std::string& message)
{
    std::cerr << "Fatal Error: " << message << std::endl;
    exit(1);  // 终止程序
}

int main()
{
    fatalError("Something went wrong!");  // 调用不会返回的函数
    std::cout << "This line will never be executed." << std::endl;  // 不可达代码
    return 0;
}
```

- 在上面的代码中：
  - `fatalError` 被标记为 `[[noreturn]]`，因为它调用了 `exit`，程序会在此终止。
  - `std::cout << "This line will never be executed."` 是不可达代码，编译器可能会发出警告或直接优化掉这行代码。

### 总结

`[[noreturn]]` 是一个有用的属性，用于明确表示函数不会返回。它可以帮助编译器优化代码，并让开发者更清晰地理解函数的语义。通常用于处理程序终止或不可恢复的错误情况。
