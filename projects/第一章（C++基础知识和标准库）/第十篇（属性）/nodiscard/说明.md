`[[nodiscard]]` 是 C++17 引入的一个属性（attribute），用于提示编译器在调用函数时，如果忽略了返回值，应该发出警告。这个属性通常用于那些返回值非常重要的函数，忽略返回值可能导致逻辑错误或资源泄漏。

### 语法

```cpp
[[nodiscard]] return_type function_name(parameters);
```

或者用于类或枚举类型：

```cpp
class [[nodiscard]] MyClass { ... };
enum class [[nodiscard]] MyEnum { ... };
```

### 使用场景

1. **资源管理函数**：例如，分配内存的函数返回一个指针，忽略返回值可能导致内存泄漏。

    ```cpp
    [[nodiscard]] void* allocateMemory(size_t size);
    ```

2. **错误处理函数**：返回错误码的函数，忽略返回值可能导致未处理的错误。

    ```cpp
    [[nodiscard]] int openFile(const std::string& filename);
    ```

3. **重要计算结果**：返回重要计算结果的函数，忽略返回值可能导致逻辑错误。

    ```cpp
    [[nodiscard]] double calculateImportantValue();
    ```

### 示例

```cpp
#include <iostream>

[[nodiscard]] int computeSomethingImportant() {
    return 42;
}

int main() {
    computeSomethingImportant(); // 编译器可能会发出警告，提示忽略了返回值
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

在上面的例子中，`computeSomethingImportant` 函数的返回值被忽略了，编译器可能会发出类似以下的警告：

```
warning: ignoring return value of function declared with 'nodiscard' attribute [-Wunused-result]
```

### 用于类或枚举类型

`[[nodiscard]]` 也可以用于类或枚举类型，表示该类型的对象或枚举值不应该被忽略。

```cpp
class [[nodiscard]] MyClass {
public:
    MyClass() { std::cout << "MyClass created" << std::endl; }
    ~MyClass() { std::cout << "MyClass destroyed" << std::endl; }
};

MyClass createMyClass() {
    return MyClass();
}

int main() {
    createMyClass(); // 编译器可能会发出警告，提示忽略了返回值
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
```

在这个例子中，`createMyClass` 函数返回一个 `MyClass` 对象，但由于 `MyClass` 被标记为 `[[nodiscard]]`，忽略返回值会导致编译器警告。

### 总结

`[[nodiscard]]` 是一个非常有用的属性，可以帮助开发者避免忽略重要的返回值，从而提高代码的健壮性和可维护性。在编写 C++ 代码时，合理使用 `[[nodiscard]]` 可以有效减少潜在的错误。
