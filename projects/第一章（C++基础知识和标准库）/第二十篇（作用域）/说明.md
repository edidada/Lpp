在 C++ 中，**作用域解析运算符（Scope Resolution Operator）** 是 `::`，它用于明确指定访问某个作用域中的成员（如变量、函数、类等）。作用域解析运算符的主要用途包括：

1. **访问全局变量或函数**。
2. **访问类的静态成员**。
3. **访问命名空间中的成员**。
4. **在类外部定义成员函数**。

以下是对作用域解析运算符的详细讲解，并结合示例代码说明其用法。

---

### 1. **访问全局变量或函数**
当局部作用域（如函数或类）中存在与全局变量或函数同名的标识符时，可以使用 `::` 访问全局作用域中的成员。

#### 示例代码
```cpp
#include <iostream>

int x = 10;  // 全局变量

int main() {
    int x = 20;  // 局部变量

    std::cout << "局部变量 x: " << x << std::endl;        // 输出 20
    std::cout << "全局变量 x: " << ::x << std::endl;      // 输出 10

    return 0;
}
```

#### 输出
```
局部变量 x: 20
全局变量 x: 10
```

#### 说明
- `x` 是局部变量，直接访问时会优先使用局部变量。
- `::x` 显式访问全局变量。

---

### 2. **访问类的静态成员**
静态成员属于类而不是类的某个对象，因此需要通过类名和作用域解析运算符来访问。

#### 示例代码
```cpp
#include <iostream>

class MyClass {
public:
    static int staticVar;  // 静态成员变量声明
};

int MyClass::staticVar = 50;  // 静态成员变量定义

int main() {
    std::cout << "静态成员变量: " << MyClass::staticVar << std::endl;  // 输出 50
    return 0;
}
```

#### 输出
```
静态成员变量: 50
```

#### 说明
- 静态成员变量 `staticVar` 属于类 `MyClass`，而不是某个对象。
- 使用 `MyClass::staticVar` 访问静态成员变量。

---

### 3. **访问命名空间中的成员**
命名空间用于组织代码，避免命名冲突。通过 `::` 可以访问命名空间中的成员。

#### 示例代码
```cpp
#include <iostream>

namespace MyNamespace {
    int value = 100;  // 命名空间中的变量
}

int main() {
    std::cout << "命名空间中的变量: " << MyNamespace::value << std::endl;  // 输出 100
    return 0;
}
```

#### 输出
```
命名空间中的变量: 100
```

#### 说明
- `value` 是命名空间 `MyNamespace` 中的变量。
- 使用 `MyNamespace::value` 访问命名空间中的变量。

---

### 4. **在类外部定义成员函数**
类的成员函数可以在类内部声明，在类外部定义。此时需要使用作用域解析运算符指定函数属于哪个类。

#### 示例代码
```cpp
#include <iostream>

class MyClass {
public:
    void print();  // 成员函数声明
};

// 成员函数定义
void MyClass::print() {
    std::cout << "Hello, World!" << std::endl;
}

int main() {
    MyClass obj;
    obj.print();  // 输出 Hello, World!
    return 0;
}
```

#### 输出
```
Hello, World!
```

#### 说明
- `print()` 函数在类 `MyClass` 中声明，在类外部定义。
- 使用 `MyClass::print` 指定该函数属于 `MyClass` 类。

---

### 5. **访问基类的成员**
在继承中，如果派生类和基类有同名成员，可以使用 `::` 访问基类的成员。

#### 示例代码
```cpp
#include <iostream>

class Base {
public:
    void print() {
        std::cout << "Base class" << std::endl;
    }
};

class Derived : public Base {
public:
    void print() {
        std::cout << "Derived class" << std::endl;
    }

    void callBasePrint() {
        Base::print();  // 调用基类的 print 函数
    }
};

int main() {
    Derived obj;
    obj.print();          // 输出 Derived class
    obj.callBasePrint();  // 输出 Base class
    return 0;
}
```

#### 输出
```
Derived class
Base class
```

#### 说明
- `Derived` 类中的 `print()` 函数隐藏了基类 `Base` 中的 `print()` 函数。
- 使用 `Base::print()` 显式调用基类的 `print()` 函数。

---

### 总结
作用域解析运算符 `::` 的主要用途包括：
1. 访问全局变量或函数。
2. 访问类的静态成员。
3. 访问命名空间中的成员。
4. 在类外部定义成员函数。
5. 访问基类的成员。

通过 `::`，可以明确指定访问哪个作用域中的成员，避免命名冲突，并提高代码的可读性和可维护性。
