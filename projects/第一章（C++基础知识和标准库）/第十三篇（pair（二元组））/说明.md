`std::pair` 是 C++ 标准库中的一个模板类，定义在 `<utility>` 头文件中。它用于将两个值组合成一个单一的对象，这两个值可以是不同的类型。`std::pair` 通常用于需要返回两个值的函数，或者在容器（如 `std::map`）中存储键值对。

---

### **`std::pair` 的基本结构**
`std::pair` 是一个模板类，其定义如下：

```cpp
template <class T1, class T2>
struct pair {
    T1 first;  // 第一个值
    T2 second; // 第二个值
};
```

- `T1` 和 `T2` 是模板参数，分别表示 `first` 和 `second` 的类型。
- `first` 和 `second` 是 `std::pair` 的两个公有成员变量，可以直接访问。

---

### **`std::pair` 的常用操作**

#### 1. **创建 `std::pair` 对象**
可以通过多种方式创建 `std::pair` 对象：

- **直接初始化**：
  ```cpp
  std::pair<int, double> p1(10, 3.14);
  ```

- **使用花括号初始化（C++11 及以上）**：
  ```cpp
  std::pair<int, double> p2{10, 3.14};
  ```

- **使用 `std::make_pair` 函数**：
  ```cpp
  auto p3 = std::make_pair(10, 3.14); // 自动推导类型
  ```

- **使用类模板参数推导（CTAD，C++17 及以上）**：
  ```cpp
  std::pair p4(10, 3.14); // 编译器自动推导为 std::pair<int, double>
  ```

---

#### 2. **访问 `std::pair` 的成员**
`std::pair` 的两个成员 `first` 和 `second` 是公有的，可以直接访问：

```cpp
std::pair<int, double> p{10, 3.14};
std::cout << "First: " << p.first << ", Second: " << p.second << std::endl;
```

输出：
```
First: 10, Second: 3.14
```

---

#### 3. **比较 `std::pair` 对象**
`std::pair` 支持比较操作（`==`, `!=`, `<`, `<=`, `>`, `>=`）。比较时，先比较 `first`，如果 `first` 相等，再比较 `second`。

```cpp
std::pair<int, int> p1{1, 2};
std::pair<int, int> p2{1, 3};

if (p1 < p2) {
    std::cout << "p1 is less than p2" << std::endl;
}
```

输出：
```
p1 is less than p2
```

---

#### 4. **赋值和交换**
- **赋值**：
  ```cpp
  std::pair<int, double> p1{10, 3.14};
  std::pair<int, double> p2;
  p2 = p1; // 复制赋值
  ```

- **交换**：
  ```cpp
  std::pair<int, double> p1{10, 3.14};
  std::pair<int, double> p2{20, 6.28};
  p1.swap(p2); // 交换 p1 和 p2 的值
  ```

---

#### 5. **结构化绑定（C++17 及以上）**
C++17 引入了结构化绑定，可以方便地将 `std::pair` 的成员解包到变量中：

```cpp
std::pair<int, double> p{10, 3.14};
auto [x, y] = p; // x = p.first, y = p.second
std::cout << "x: " << x << ", y: " << y << std::endl;
```

输出：
```
x: 10, y: 3.14
```

---

### **`std::pair` 的典型用途**

#### 1. **返回多个值**
函数可以通过 `std::pair` 返回两个值：

```cpp
std::pair<int, int> divide(int dividend, int divisor) {
    int quotient = dividend / divisor;
    int remainder = dividend % divisor;
    return {quotient, remainder};
}

int main() {
    auto result = divide(10, 3);
    std::cout << "Quotient: " << result.first << ", Remainder: " << result.second << std::endl;
}
```

输出：
```
Quotient: 3, Remainder: 1
```

---

#### 2. **在 `std::map` 中存储键值对**
`std::map` 的每个元素都是一个 `std::pair`，其中 `first` 是键，`second` 是值：

```cpp
std::map<std::string, int> scores = {{"Alice", 90}, {"Bob", 85}};

for (const auto& [name, score] : scores) {
    std::cout << name << ": " << score << std::endl;
}
```

输出：
```
Alice: 90
Bob: 85
```

---

#### 3. **排序和自定义比较**
`std::pair` 可以用于排序，例如对一组点按 x 坐标排序：

```cpp
std::vector<std::pair<int, int>> points = {{1, 2}, {3, 4}, {0, 0}};
std::sort(points.begin(), points.end());

for (const auto& [x, y] : points) {
    std::cout << "(" << x << ", " << y << ")" << std::endl;
}
```

输出：
```
(0, 0)
(1, 2)
(3, 4)
```

---

### **`std::pair` 的局限性**
- `std::pair` 只能存储两个值。如果需要存储更多值，可以使用 `std::tuple`。
- `std::pair` 的成员名称 `first` 和 `second` 是固定的，语义不够明确，可以通过自定义结构体替代。

---

### **总结**
`std::pair` 是一个简单而强大的工具，用于将两个值组合在一起。它在函数返回值、容器存储和算法中都有广泛的应用。通过结合 C++17 的结构化绑定和 CTAD，`std::pair` 的使用变得更加简洁和直观。
