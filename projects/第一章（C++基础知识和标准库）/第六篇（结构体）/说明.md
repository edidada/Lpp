export module employee;：
 - 这是一个模块声明。模块 employee 向其他代码开放，允许其他文件导入并使用该模块中的内容。模块化编程的目的是提高代码的组织性和减少编译时间。

export struct Employee { ... }：
 - export 关键字使得 Employee 结构体可以被外部模块访问。
 - Employee 结构体包含四个字段：firstInitial（名字首字母）、lastInitial（姓氏首字母）、employeeNumber（员工编号）和 salary（工资）。这些字段用来表示一个员工的基本信息。
