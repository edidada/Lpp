什么是变量？

在编程中，变量是一个用于存储数据的命名内存位置。变量有三个关键属性：

- **名称：** 变量的标识符，用于在代码中引用它。

- **类型：** 变量存储的数据类型（如 int、double、string 等），决定了变量可以存储的数据种类和范围。

- **值：** 变量当前存储的具体数据。

变量在使用前通常需要初始化（即赋予一个初始值），否则它的值可能是未定义的（随机值），这会导致程序行为不可预测。

初始化变量的最佳实践：
```c++
int x = 0;       // 传统初始化
int y{ 0 };      // 列表初始化（推荐）
int z{};         // 值初始化（默认值为 0）
```
