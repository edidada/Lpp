`std::numeric_limits` 是 C++ 标准库中的一个模板类，定义在 `<limits>` 头文件中。它的作用是**提供各种数值类型的属性信息**，例如最大值、最小值、精度、是否有符号等。通过 `numeric_limits`，可以在编译时查询和操作数值类型的特性。

---

### **主要作用**
1. **查询数值类型的极值**：
    - 获取类型的最大值（`max()`）。
    - 获取类型的最小值（`min()`）。
    - 获取类型的最低值（`lowest()`，对于浮点数通常是最大的负数）。

2. **查询数值类型的特性**：
    - 判断类型是否有符号（`is_signed`）。
    - 判断类型是否是整数类型（`is_integer`）。
    - 判断类型是否是精确表示的（`is_exact`）。
    - 获取类型的精度（`digits` 或 `digits10`）。

3. **查询特殊值**：
    - 获取无穷大（`infinity()`，仅适用于浮点数）。
    - 获取静默的 NaN（`quiet_NaN()`，仅适用于浮点数）。
    - 获取信号 NaN（`signaling_NaN()`，仅适用于浮点数）。

4. **查询其他属性**：
    - 获取类型的基数（`radix`，通常是 2 或 10）。
    - 获取类型的最小指数（`min_exponent`，仅适用于浮点数）。
    - 获取类型的最大指数（`max_exponent`，仅适用于浮点数）。

---

### **常用成员函数和静态成员**
以下是 `numeric_limits` 常用的成员函数和静态成员：

| 成员函数/静态成员          | 作用                                                                 |
|---------------------------|----------------------------------------------------------------------|
| `max()`                   | 返回类型的最大值。                                                  |
| `min()`                   | 返回类型的最小值（对于整数是最小值，对于浮点数是最小正数）。         |
| `lowest()`                | 返回类型的最低值（对于浮点数通常是最大的负数）。                    |
| `is_signed`               | 返回类型是否有符号（`true` 或 `false`）。                           |
| `is_integer`              | 返回类型是否是整数类型（`true` 或 `false`）。                       |
| `is_exact`                | 返回类型是否是精确表示的（`true` 或 `false`）。                     |
| `digits`                  | 返回类型的位数（二进制位数，不包括符号位）。                        |
| `digits10`                | 返回类型的十进制精度（十进制有效数字位数）。                        |
| `epsilon()`               | 返回类型的机器 epsilon（表示 1 和比 1 大的最小值的差）。            |
| `infinity()`              | 返回类型的正无穷大（仅适用于浮点数）。                              |
| `quiet_NaN()`             | 返回类型的静默 NaN（仅适用于浮点数）。                              |
| `signaling_NaN()`         | 返回类型的信号 NaN（仅适用于浮点数）。                              |
| `round_style`             | 返回类型的舍入方式（例如 `round_toward_zero`）。                    |
| `has_infinity`            | 返回类型是否支持无穷大（`true` 或 `false`）。                       |
| `has_quiet_NaN`           | 返回类型是否支持静默 NaN（`true` 或 `false`）。                     |
| `has_signaling_NaN`       | 返回类型是否支持信号 NaN（`true` 或 `false`）。                     |

---

### **总结**
`std::numeric_limits` 是一个非常有用的工具，用于在编译时查询数值类型的属性。它可以帮助开发者编写更通用、更健壮的代码，尤其是在处理不同平台或不同数值类型时。通过它，可以避免硬编码数值类型的极值或特性，从而提高代码的可移植性和可维护性。
