### C++ 自定义函数及函数重载

在 C++ 中，函数是程序的基本构建块之一。通过自定义函数，可以将代码模块化，提高代码的可读性、可维护性和复用性。函数重载（Function Overloading）是 C++ 的一个重要特性，允许在同一作用域内定义多个同名函数，但这些函数的参数列表必须不同。

---

### 1. 自定义函数

#### 1.1 函数的定义
函数由以下部分组成：
- **返回类型**：函数返回值的数据类型（如 `int`、`double`、`void` 等）。
- **函数名**：函数的标识符，用于调用函数。
- **参数列表**：函数接受的输入参数，可以有零个或多个。
- **函数体**：函数的具体实现代码。

#### 1.2 函数的声明和定义
- **函数声明**（也称为函数原型）：告诉编译器函数的存在，包括函数名、返回类型和参数列表。
- **函数定义**：提供函数的具体实现。

#### 示例代码
```cpp
#include <iostream>
using namespace std;

// 函数声明
int add(int a, int b);

// 函数定义
int add(int a, int b)
{
    return a + b;
}

int main()
{
    int result = add(3, 5); // 调用函数
    cout << "Result: " << result << endl; // 输出 8
    return 0;
}
```

#### 1.3 函数的调用
- 通过函数名和参数列表调用函数。
- 调用函数时，实参（实际参数）的值会传递给形参（形式参数）。

---

### 2. 函数重载

#### 2.1 什么是函数重载？
函数重载允许在同一作用域内定义多个同名函数，但这些函数的参数列表必须不同（参数的类型、数量或顺序不同）。编译器根据调用时提供的参数类型和数量来决定调用哪个函数。

#### 2.2 函数重载的规则
- 函数名必须相同。
- 参数列表必须不同（参数的类型、数量或顺序）。
- 返回类型可以相同也可以不同，但仅靠返回类型不同不足以构成重载。

#### 2.3 函数重载的优点
- 提高代码的可读性：可以使用相同的函数名处理不同类型的数据。
- 简化代码：避免为功能相似但参数不同的函数起不同的名字。

#### 示例代码
```cpp
#include <iostream>
using namespace std;

// 重载函数 1：接受两个 int 参数
int add(int a, int b)
{
    cout << "Integer addition: ";
    return a + b;
}

// 重载函数 2：接受两个 double 参数
double add(double a, double b)
{
    cout << "Double addition: ";
    return a + b;
}

// 重载函数 3：接受三个 int 参数
int add(int a, int b, int c)
{
    cout << "Three-integer addition: ";
    return a + b + c;
}

int main()
{
    cout << add(3, 5) << endl;           // 调用 add(int, int)
    cout << add(3.5, 2.5) << endl;       // 调用 add(double, double)
    cout << add(1, 2, 3) << endl;        // 调用 add(int, int, int)
    return 0;
}
```

#### 输出结果
```
Integer addition: 8
Double addition: 6
Three-integer addition: 6
```

#### 2.4 函数重载的底层原理
- 编译器通过名称修饰（Name Mangling）为每个重载函数生成唯一的内部名称。
- 名称修饰会将函数名和参数类型编码在一起，确保链接器能够正确区分不同的重载函数。

### 3. 函数重载与默认参数

#### 3.1 默认参数
C++ 允许为函数参数提供默认值。如果调用函数时未提供某个参数，则使用默认值。

#### 3.2 默认参数与函数重载的冲突
- 如果函数重载和默认参数结合不当，可能会导致二义性（Ambiguity），编译器无法确定调用哪个函数。

#### 示例代码
```cpp
#include <iostream>
using namespace std;

// 重载函数 1
void print(int a)
{
    cout << "Integer: " << a << endl;
}

// 重载函数 2（带有默认参数）
void print(int a, int b = 10)
{
    cout << "Two integers: " << a << ", " << b << endl;
}

int main()
{
    print(5);       // 二义性错误：编译器无法确定调用哪个函数
    print(5, 15);   // 正确：调用 print(int, int)
    return 0;
}
```

#### 解决方法
- 避免在重载函数中使用默认参数，或者确保调用时不会产生二义性。

### 4. 函数重载与模板

#### 4.1 函数模板
函数模板允许编写通用的函数，适用于多种数据类型。

#### 4.2 函数模板与重载的结合
- 函数模板可以替代部分函数重载的场景。
- 函数模板和重载函数可以共存，编译器会优先选择最匹配的函数。

#### 示例代码
```cpp
#include <iostream>
using namespace std;

// 函数模板
template <typename T>
T add(T a, T b)
{
    cout << "Template addition: ";
    return a + b;
}

// 重载函数
int add(int a, int b)
{
    cout << "Integer addition: ";
    return a + b;
}

int main()
{
    cout << add(3, 5) << endl;           // 调用重载函数 add(int, int)
    cout << add(3.5, 2.5) << endl;       // 调用模板函数 add(double, double)
    return 0;
}
```

#### 输出结果
```
Integer addition: 8
Template addition: 6
```

### 5. 总结

| 特性            | 自定义函数                          | 函数重载                              |
|-----------------|-------------------------------------|---------------------------------------|
| 定义            | 通过返回类型、函数名、参数列表定义   | 多个同名函数，参数列表不同             |
| 优点            | 模块化、复用性高                   | 提高代码可读性，简化函数命名           |
| 适用场景        | 单一功能的实现                     | 处理不同类型或数量的参数               |
| 注意事项        | 避免函数过长，保持单一职责原则       | 避免二义性，确保参数列表不同           |

通过自定义函数和函数重载，可以编写出更灵活、更易维护的 C++ 代码。
