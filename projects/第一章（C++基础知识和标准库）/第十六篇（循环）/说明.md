在 C++ 中，循环是一种控制结构，用于重复执行一段代码，直到满足特定条件。C++ 提供了多种循环结构，每种循环都有其特定的用途和语法。以下是 C++ 中常见的循环结构及其详细说明：

---

## 1. **`while` 循环**
`while` 循环在条件为真时重复执行代码块。它的特点是先检查条件，再决定是否执行循环体。

### 语法：
```cpp
while (condition) {
    // 循环体
}
```

### 示例：
```cpp
int i = 0;
while (i < 5) {
    println("i = {}", i); // 打印 i 的值
    ++i; // i 自增
}
```

### 特点：
- 如果条件一开始就为假，循环体不会执行。
- 适合用于不确定循环次数的情况。

---

## 2. **`do-while` 循环**
`do-while` 循环与 `while` 循环类似，但它的特点是先执行循环体，再检查条件。因此，循环体至少会执行一次。

### 语法：
```cpp
do {
    // 循环体
} while (condition);
```

### 示例：
```cpp
int i = 0;
do {
    println("i = {}", i); // 打印 i 的值
    ++i; // i 自增
} while (i < 5);
```

### 特点：
- 循环体至少执行一次。
- 适合用于需要先执行一次操作，再检查条件的情况。

---

## 3. **`for` 循环**
`for` 循环是一种更紧凑的循环结构，通常用于已知循环次数的情况。它将初始化、条件检查和更新操作集中在一行中。

### 语法：
```cpp
for (初始化; 条件; 更新) {
    // 循环体
}
```

### 示例：
```cpp
for (int i = 0; i < 5; ++i) {
    println("i = {}", i); // 打印 i 的值
}
```

### 特点：
- 初始化、条件检查和更新操作都在 `for` 语句中完成。
- 适合用于已知循环次数的情况。

---

## 4. **范围 `for` 循环**
范围-based `for` 循环是 C++11 引入的特性，用于遍历容器（如数组、`std::vector` 等）中的元素。

### 语法：
```cpp
for (元素类型 变量 : 容器) {
    // 循环体
}
```

### 示例：
```cpp
std::array<int, 4> arr = {1, 2, 3, 4};
for (int i : arr) {
    println("i = {}", i); // 打印数组中的每个元素
}
```

### 特点：
- 无需手动管理索引或迭代器。
- 适合用于遍历容器中的元素。

---

## 5. **带初始化器的范围 `for` 循环**
C++20 引入了带初始化器的范围 `for` 循环，允许在循环中初始化变量。

### 语法：
```cpp
for (初始化; 元素类型 变量 : 容器) {
    // 循环体
}
```

### 示例：
```cpp
for (std::array<int, 4> arr = {1, 2, 3, 4}; int i : arr) {
    println("i = {}", i); // 打印数组中的每个元素
}
```

### 特点：
- 可以在循环中初始化变量，减少外部作用域的污染。
- 适合用于需要临时变量的场景。

---

## 6. **无限循环**
无限循环是指没有退出条件的循环，通常需要结合 `break` 语句来手动退出。

### 语法：
```cpp
while (true) {
    // 循环体
    if (条件) {
        break; // 退出循环
    }
}
```

### 示例：
```cpp
int i = 0;
while (true) {
    println("i = {}", i);
    ++i;
    if (i >= 5) {
        break; // 当 i >= 5 时退出循环
    }
}
```

### 特点：
- 需要手动控制循环退出。
- 适合用于需要不断执行直到满足特定条件的场景。

---

## 7. **`break` 和 `continue` 语句**
- **`break`**: 用于立即退出当前循环。
- **`continue`**: 用于跳过当前迭代，直接进入下一次循环。

### 示例：
```cpp
for (int i = 0; i < 10; ++i) {
    if (i == 5) {
        break; // 当 i == 5 时退出循环
    }
    if (i % 2 == 0) {
        continue; // 跳过偶数
    }
    println("i = {}", i);
}
```

---

## 8. **嵌套循环**
循环可以嵌套使用，即在一个循环内部再使用另一个循环。

### 示例：
```cpp
for (int i = 0; i < 3; ++i) {
    for (int j = 0; j < 3; ++j) {
        println("i = {}, j = {}", i, j);
    }
}
```

### 特点：
- 外层循环每执行一次，内层循环会完整执行一遍。
- 适合用于处理多维数据或复杂逻辑。

---

## 总结
| 循环类型                    | 特点                                                                 |
|-------------------------|----------------------------------------------------------------------|
| `while` 循环              | 先检查条件，再执行循环体。                                           |
| `do-while` 循环           | 先执行循环体，再检查条件。                                           |
| `for` 循环                | 初始化、条件检查和更新操作集中在一行中。                             |
| 基于范围 `for` 循环           | 遍历容器中的元素，无需手动管理索引或迭代器。                         |
| 带初始化器的范围 `for` 循环 | 在循环中初始化变量，减少外部作用域的污染。                           |
| 无限循环                    | 需要手动控制循环退出。                                               |
| 嵌套循环                    | 适合处理多维数据或复杂逻辑。                                         |

通过合理选择循环结构，可以更高效地实现重复性任务。
