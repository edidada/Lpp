命名空间（namespace）

命名空间是一个声明区域，用于将代码（如函数、类、变量等）封装在一个特定的作用域内。通过命名空间，可以避免不同库或模块之间的命名冲突。

简单示例：
```c++
namespace mycode {
    void foo() {
        println("mycode 命名空间中的 foo() 函数。");
    }
}

namespace othercode {
    void foo() {
        println("othercode 命名空间中的 foo() 函数。");
    }
}

int main() {
    mycode::foo();  // 调用 mycode 命名空间中的 foo
    othercode::foo(); // 调用 othercode 命名空间中的 foo
}
```
